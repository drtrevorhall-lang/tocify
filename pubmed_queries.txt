# PubMed E-utilities queries. Publisher-agnostic coverage.
#
# Format:  Name | PubMed query
# Lines starting with # are ignored.
#
# Why this exists: RSS ToC feeds break when journals change publishers or platforms,
# and they miss papers published in journals you don't subscribe to. PubMed E-utilities
# is a stable NCBI API and searches everything indexed in MEDLINE. Each query is run
# with reldate = LOOKBACK_DAYS so you only get new records.
#
# Syntax notes: [tiab] = title/abstract, [MeSH Terms] = indexed subject heading,
# [Journal] = journal name. Truncation with * works in [tiab] but NOT inside quotes
# unless the phrase is short. Test queries at https://pubmed.ncbi.nlm.nih.gov first.
